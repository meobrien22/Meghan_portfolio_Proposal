NORTHSTAR OUTFITTERS / MANUFACTURING & AI

Right gear.
Ready on time.

A fictional manufacturer supplies U.S. Army soldiers with uniforms, boots and tactical gear. This workshop turns a size-specific shortage into a clear, human-approved production plan.

Explore the sticky notes ↗Try the planning prototype ↗

The problem

120 pairs of boots required. Only 72 released in the correct size. Production and quality teams need a dependable plan for the remaining 48.

My contribution

JTBD framing, cross-team facilitation, agent experience design, interactive prototyping and data storytelling.

The output

A planning assistant concept that connects demand, inventory, capacity and quality evidence for a human decision.

01 / MY APPROACH

Start with the soldier. Align the factory.

I connect the person who needs correctly fitting gear with the teams who plan, manufacture and release it. Together, we define the progress each person needs to make.

THE OUTPUT

Two Jobs to Be Done, an evidence wall and a shared definition of success.

02 / MY APPROACH

Turn a shortage into a clear decision.

I map demand, inventory, materials, production and quality. The agent concept brings those records into a recovery plan that a person can inspect and approve.

THE OUTPUT

An agent blueprint with traceable inputs, clear responsibilities and human review.

See the workflow ↗Compare agent designs ↗Try the planning prototype ↗
03 / MY APPROACH

Test the plan before making a promise.

I challenge the plan with wrong sizes, held lots, stale records and missed dates. Then I define a pilot and the data story: from Fabric to Power BI, showing delivery reliability, exceptions and planning effort.

THE OUTPUT

Six test scenarios, an owned decision log and a measurable pilot plan.
